# Azure Study Deck

"Build a clean, modern, beginner-friendly web app called 'Azure Concept Flashcards' (Unofficial AZ-900 Study Tool).

Features needed:

Flashcard area with a 3D flip animation when clicked.

Front shows a Question/Concept, Back shows the Answer/Definition.

Navigation buttons: 'Previous', 'Next', and 'Randomize/Shuffle'.

Progress bar showing progress (e.g., 'Card 3 of 10').

Category tabs at the top (e.g., 'Cloud Concepts', 'Azure Architecture', 'Security & Governance').

Footer warning: 'Unofficial study tool. Not affiliated with Microsoft.'

Color scheme: Modern dark/light blue theme."
